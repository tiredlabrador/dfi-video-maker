DFI

Video Maker

Turns a track into a spinning-record video for Instagram. It runs on your own Mac.

What you need first

Open Terminal (press ⌘ + space, type Terminal, press return), then paste each of these and press return.

1. Homebrew, which installs everything else:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

It asks for your Mac password. Typing it shows nothing on screen — that's normal. Skip this if you already have Homebrew.

2. ffmpeg, which actually makes the video:

brew install ffmpeg

Getting the app

cd ~/Documents && git clone https://github.com/tiredlabrador/dfi-video-maker.git && cd dfi-video-maker && ./run

That downloads it, sets it up, and opens it in your browser.

Every time after that

Open the dfi-video-maker folder in Documents and double-click run. Leave the Terminal window open while you work — that window is the app. Press Ctrl + C in it when you're done.

Updates

There's nothing to install. It fetches the latest version each time it starts.

The brand font

Squid Boy is licensed, so it isn't in the public download. Without it, videos still render but the captions use a substitute — the app tells you at the top of the page if it's missing. Ask Dom for SquidBoy.otf and put it in assets/fonts.
